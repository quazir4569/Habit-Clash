# Habit-Clash

Habit-Clash is a gamified Android habit-tracking app created for the Capstone 2025 project.

Features:
Create and track personal habits
Monitor habit progress and consistency
Gamify habit tracking to encourage motivation
User authentication
Cloud-based data storage
Tech Stack
Kotlin
Jetpack Compose
Material 3
Firebase Authentication
Cloud Firestore
Android Navigation
Requirements
Android Studio
Android SDK 35+
Minimum Android version: Android 7.0 (API 24)

Purpose:
Habit-Clash makes building healthy habits more engaging by combining habit tracking with gamification.

Project:
Developed as part of the Capstone 2025 project.
